Resource Dumper is a utility program for classic (pre-OS X) versions of MacOS. It can change the type of resources in a file's resource fork, or can dump selected resources from a file's resource fork to data files. If you don't know what this means, you probably don't need it.

The program's manual is available [here](docs/manual.html).
